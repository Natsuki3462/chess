# ChessFloat

置顶半透明的桌面浮窗，用肉眼复刻真实对局、由本地 Stockfish 实时提示最佳着法。
纯本地运行，不截图、不识别、不联网、不上传任何东西。

---

## 快速开始

```bash
git clone <本仓库地址>
cd ChessFloat
```

**第 1 步：放引擎**（仓库不含 99MB 的二进制）

从 <https://github.com/official-stockfish/Stockfish/releases> 下载
`stockfish-windows-x86-64-universal.zip`，解压后把里面的 exe 改名为 `stockfish.exe`，
放到 `engine\` 目录下。目录里已有 `Copying.txt` / `AUTHORS`（GPLv3 要求随附）。

> 国内网络下载 GitHub Release 常常卡住，可以用镜像前缀：
> `https://ghfast.top/https://github.com/official-stockfish/Stockfish/releases/download/sf_19/stockfish-windows-x86-64-universal.zip`

**第 2 步：装依赖**

双击 **`install.bat`**（建虚拟环境 + 装 PyQt6/python-chess + 自检，全部落在本文件夹内，
不污染系统 Python、不写注册表）。

**第 3 步：启动**

双击 **`run.bat`**（或 `run-debug.bat` 带控制台日志）。浮窗上选择执白/执黑，
之后循环：看到对手走子 → 在浮窗上复刻 → 等箭头 → **空格采纳**。

## 界面

```
┌────────────────────────────────────────────┐
│ ChessFloat  轮你走 · 建议 Bb5 · 深度 22  +0.21  ⇧ ⚙ ⊟ ✕ │
├────────────────────────────────────────────┤
│                                            │
│              8 × 8 自绘棋盘                 │
│     （上一步高亮 / 将军红晕 / 绿箭头=建议）    │
│                                            │
├────────────────────────────────────────────┤
│ 1.e4  e5  2.Nf3  Nc6  3.Bb5   ← 点任意一步回退 │
├────────────────────────────────────────────┤
│ ◐ ────●────          [采纳]  ↩  ↪  ⇅  ⟳     │
└────────────────────────────────────────────┘
```

- **顶栏**：拖住可移动窗口；`A` 自动采纳开关、`⇧` 置顶、`⚙` 设置、`⊟` 紧凑模式（只留棋盘）、`✕` 退出
- **历史条**：点第 N 步即回退/前进到该步，绿色为当前所在步
- **底栏**：透明度滑块（15%–100%，1% 无级，右侧实时显示百分比，点 `◐` 一键复位）、
  采纳按钮、撤销 / 重做 / 翻转 / 新局
- **右下角**：拖动缩放窗口；棋盘始终取 `min(宽,高)` 保持正方形

## 快捷键

| 键 | 作用 |
| --- | --- |
| `空格` | 采纳引擎建议（一键走子；只要棋盘上还看得见箭头就能走，含撤销后恢复的箭头） |
| `Ctrl+Z` | 撤销一步（按住连续撤销） |
| `Ctrl+Y` | 重做 |
| `F` | 翻转视角 |
| `N` | 新开一局（重新选择先后手） |
| `Esc` | 取消当前选中 |
| `↑` / `↓` | 透明度 −2% / +2%（细调） |
| `Ctrl` + 滚轮 | 在浮窗任意位置无级调透明度（一格 2%） |
| `Ctrl+1` ~ `Ctrl+4` | 切换分析强度：省电 / 均衡 / 深度 / 极限 |
| 双击顶栏 | 切换紧凑模式 |

鼠标：**按住棋子直接拖到目标格**，或者左键点起点 → 点终点（两种都行）；右键/Esc 取消选择；
撤销按钮可长按连续撤销。拖到非法位置棋子会回弹并保持选中，方便重新拖。

## 自动采纳（顶栏 `A`）

打开后引擎一出建议就自动把棋子走掉，连空格都不用按：

- 箭头先亮 **0.32 秒**再走子，给眼睛一个"这是引擎的选择"的提示
- 打开开关那一刻如果棋盘上已经有建议，会立刻走掉，不用等下一轮
- **撤销 / 重做 / 回退会自动关掉它**——否则你撤一步，它立刻又走回去，等于撤不动
- 只在轮到你走时生效；对手回合不分析、不走子，你复刻完对手着法它才接管
- 你正按住棋子拖拽或选中着想的时候，它会避让，不抢你的手

## 三条核心机制

**1. 人眼替代 CV —— 只输入对手着法**
浮窗镜像真实对局，你只需复刻对手那一步；自己的着法由引擎建议后一键采纳，输入量最小。

**2. 局面归 python-chess，计算归 Stockfish**
`chess.Board` 是唯一真源，负责合法性校验、历史栈、撤销、FEN。
轮到你走时，局面一变 → 防抖 300ms → 触发 Stockfish 限时分析（默认「均衡」档 2000ms，难局面自动加时）；
对手回合不跑引擎、不出箭头（不给对方算棋，也省 CPU）。
每次局面变化 `version += 1`，分析结果带着 version 回传，主线程对不上号就丢弃，箭头永远不会错位。

**3. UI 只做三件事：画棋盘、收点击、画箭头**
PyQt6 无边框置顶半透明窗口，`paintEvent` 自绘 8×8 网格与棋子，点击坐标按视角翻转映射，
引擎结果画成矢量箭头。引擎跑在子线程，主线程只渲染。

## 实现要点

- **棋子完全自绘**：6 种棋子都是 `QPainterPath` 矢量剪影（`app/pieces.py`），不依赖任何字体或图片，缩放到任意尺寸都清晰。
- **引擎线程可打断**：`EngineWorker` 用 `engine.analysis()` 逐节点读取，新请求/撤销时立刻 `stop()`，不会卡在旧分析里；空闲时阻塞等待，CPU ≈ 0。
- **版本号校验**：`AnalysisResult.version != session.version` 直接丢弃，快速连走也不会出现过期箭头。
- **箭头只有两种状态**：绿色 = 当前局面的建议；灰色 = 上一轮遗留的建议（走子/撤销后到新结果回来之前）。
  走子瞬间箭头不会消失，新结果到达后无缝替换；撤销回到原位时旧箭头若仍合法，会立刻恢复成绿色，不用等重新分析。
  按空格时"看得见就能走"：箭头对应的着法只要在当前局面合法，就直接执行，不会出现"箭头在、空格没反应"。
- **拖拽走子**：按下棋子后位移超过 4px 即进入拖拽，原格棋子跟随光标、合法落点套绿框，
  松手落子；位移不足则按普通点击处理（选中/取消）。拖拽与点击共用同一套 `find_move` 校验，
  翻转视角下的像素↔格子映射同样生效。
- **自动采纳是"带守卫的自动"**：延迟 320ms 用 `QTimer` 触发，回调里三重校验
  （开关仍开、`version` 未变、着法仍合法），并避开用户正在拖拽/选中的时刻；
  撤销类操作会主动关掉开关，杜绝"撤一步被立刻走回去"的死循环。
- **翻转只影响显示**：`session.flipped` 只参与像素↔格子的映射，FEN 与规则判定完全不受影响。
- **撤销语义**：撤销的着法进入 redo 栈，可重做；新走子会截断 redo 分支。

## 分析强度（设置里切换，或 `Ctrl+1~4`）

档位越高越强，代价是箭头来得越慢。默认「均衡」。

| 档位 | 限时 | 线程 | Hash | 走子→箭头 | 开局深度 | 残局（车兵） |
| --- | --- | --- | --- | --- | --- | --- |
| 省电 | 800ms | 2 | 64MB | ≈1.1s | 24 层 | 30 层 · +10.14（看不见杀） |
| **均衡（默认）** | 2000ms | 4 | 256MB | ≈2.3s | 29 层 | 35 层 · +85.83 |
| 深度 | 3500ms | 6 | 512MB | ≈3.8s | 30 层 | **64 层 · #17（17 步杀）** |
| 极限 | 6000ms | 8 | 1024MB | ≈6.3s | 32 层 | **85 层 · #15** |

> 实测同一残局：省电档只有 +10.14，完全看不见杀；深度档直接给出 #17。
> 这就是"多给算力"最直观的收益。

### 再往上还有用吗？（实测：基本没有了）

选「自定义」可以手动设到 30s / 32 线程 / 4096MB，但实测边际收益很快见底。

同一中局，固定 6 秒只加线程：

| 线程 / Hash | 深度 | 节点 | 首选 |
| --- | --- | --- | --- |
| 8T / 1024MB | 35 | 36.7M | d4c5 |
| 16T / 2048MB | 35 | 54.5M | d4c5 |
| 24T / 3072MB | **32** | 68.5M | d4c5 |

节点翻倍但深度不涨，24 线程反而降 3 层——Lazy SMP 把搜索摊薄了。**8 线程就够，再加是浪费。**

同一中局，16 线程只加时间：3s→31 层、6s→36 层、12s→44 层，但**首选着法和评估一直没变**。
也就是说：结论早就收敛了，继续算只是让引擎更"确信"，不会换那步棋。

结论：**实时提示场景下，「深度」档已经接近饱和**；「极限」档留着给关键局面确认用。
真正还能提升的不是算力，而是信息维度（多候选、对手失误评分）。

### 自适应思考时间（默认开启）

不是固定限时，而是按局面难度分配，基础值 × 0.4~2.5：

| 局面特征 | 系数 |
| --- | --- |
| 残局（≤10 子） | +0.60（杀棋与技巧全靠深度） |
| 少子残局（≤16 子） | +0.25 |
| 被将军 | +0.30 |
| 选择多（≥35 个合法着法） | +0.25 |
| 上一步评估剧烈波动（>1.0） | +0.40（多半有战术） |
| 中局强制着法（≤3 步可走） | −0.35 |

实测「均衡」档：开局 2000ms、残局 3200ms、残局+将军 3800ms。
既保证残局看得见杀，又不在无脑局面烧 CPU。

## 会不会和游戏抢 CPU？

实测（32 逻辑核，极限档 8 线程 1024MB）：

```
空闲基线 CPU:      1.8%
8 线程分析中:     20.0%     ← 理论 8/32 = 25%，实际还低一些
分析结束后:        0.6%
```

三层保险，基本不用担心：

1. **只在轮到你走时才分析**。对手回合引擎完全空闲（不分析、不出建议），
   所以占用是"脉冲式"的：复刻完对手着法 → 算 2~6 秒 → 走子 → 回到空闲。
2. **引擎进程默认 BELOW_NORMAL 优先级**（设置里可关）。没有竞争时不影响引擎自己的速度，
   一旦游戏/视频抢 CPU，Windows 会优先满足它们，引擎主动让路。
3. **档位可降**。玩大型游戏时按 `Ctrl+1` 切「省电」（2 线程 800ms），占用约 6%，几乎无感。

> 唯一的真实风险不是平均占用，而是"分析那几秒正好撞上游戏的关键帧"。
> 如果玩的是对帧率极敏感的竞技游戏，建议直接按 `Ctrl+1` 或关掉浮窗。

## 常见问题

**箭头一直不出现？**
看顶栏状态：显示"未找到 Stockfish"就把引擎放到 `engine\` 下，或在 `⚙` 里指定路径。
显示"分析中…"卡住就按 `Ctrl+1` 切到省电档（800ms）试试，或调小 Hash。

**觉得引擎不够强？**
按 `Ctrl+3`/`Ctrl+4` 切到「深度」/「极限」档，代价是箭头慢 1~4 秒。
残局里这个差别很直观：省电档可能只有 +10 的评估，深度档能直接报出 #17 杀。

**点了棋子没反应 / 提示"现在轮到白方走，黑方棋子暂时不能动"？**
浮窗只允许走当前该走的一方。轮到对手时你的任务是**复刻他的着法**，此时对方棋子是锁住的，
点了会红框闪一下并在顶栏说明原因。如果复刻错了，`Ctrl+Z` 撤销即可。

**浮窗挡住了想看的地方？**
拖右下角缩小，或把透明度往下拖（最低 15%，几乎只剩一层玻璃），或 `⊟` 进入紧凑模式只留棋盘。
透明度的四种调法：拖底栏滑块（1% 无级）、`Ctrl`+滚轮、`↑`/`↓` 微调、点 `◐` 复位 94%。

**引擎想换更强的版本？**
到 <https://github.com/official-stockfish/Stockfish/releases> 下 Windows x64 包，
把 exe 改名为 `stockfish.exe` 覆盖 `engine\` 里的文件即可，无需改代码。

## 合规边界（重要）

本软件**仅用于个人复盘、离线对局分析、自建环境练习**。

在在线对战平台使用引擎辅助属于违规行为，会破坏对局公平。本软件不面向、也不适配该场景，
并且刻意不包含任何图像识别、屏幕读取、自动输入/注入能力 —— 局面完全由用户自己输入。
